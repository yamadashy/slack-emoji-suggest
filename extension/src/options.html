絵文字リアクションのおすすめ

メッセージ本文は、そのメッセージにポインタを合わせたときとピッカーを開いたときだけ送られます。 チャンネル全体を読みに行くことはありません。

API キー

キーはこのブラウザのローカル領域にだけ保存され、ページ側のスクリプトには渡りません。

カスタム絵文字

ワークスペースの絵文字を Slack の画面から取り込んで、候補に加えます。取り込みは絵文字ピッカーを 開いて一覧を読むだけで、Slack の API は呼びません。Slack のタブを開いた状態で実行してください。

名前だけで意味が伝わらないもの（人の顔など）は、ここで説明を足せます。1 行 1 件、 :name: 説明。書かなかった絵文字は名前だけで判断されます。

標準の絵文字の候補

1 行 1 件、:shortcode: 説明 の形式。説明はモデルがそのまま読むので英語のままが無難です。
